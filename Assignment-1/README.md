## Objective
To demonstrate the concept of String immutability in Java by performing multiple concatenation operations and verifying that each concatenation creates a new String object using identity hash codes.

## Concepts Used
- String Immutability
- String Concatenation
- Object Identity
- For Loop
- System.identityHashCode()

## Program Description
This program starts with a string and performs multiple concatenation operations inside a loop. After each concatenation, the identity hash code of the string is displayed. The changing identity hash codes prove that a new String object is created after every concatenation, demonstrating that Java Strings are immutable.
